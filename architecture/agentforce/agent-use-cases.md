# Agentforce Use Cases

## 1. Next Best Action Agent

Uses Data Cloud profile attributes and engagement history to recommend the next action.

Examples:
- Send follow-up email
- Route to service representative
- Recommend relevant product or service content
- Suppress outreach because of consent status

## 2. Customer Context Agent

Summarizes:
- Customer profile
- Recent engagement
- Open cases
- Campaign history

## 3. Service Automation Agent

Answers common customer questions using approved knowledge sources and Salesforce record context.
