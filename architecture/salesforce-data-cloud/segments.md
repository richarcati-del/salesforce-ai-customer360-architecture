# Data Cloud Segments

## Example Segments

### High Intent Prospect
Criteria:
- Clicked campaign email
- Visited product page
- Submitted interest form
- Email consent = true

### Existing Customer
Criteria:
- Active customer status
- Recent engagement within 90 days
- Email consent = true

### Suppressed Audience
Criteria:
- Email consent = false
- Do not contact flag = true
