# Recruiter Talking Points

This project demonstrates my ability to design an enterprise AI and data architecture using AWS, Snowflake, Salesforce Data Cloud, SFMC, and Agentforce.

## Key Strengths Demonstrated

- Salesforce architecture leadership
- Data Cloud identity resolution and segmentation
- Agentforce next-best-action use cases
- SFMC personalization and journey activation
- AWS event-driven integration
- Snowflake data modeling and transformation
- Consent-aware customer engagement
- REST API and enterprise integration design

## Interview Pitch

I designed this as a reference architecture to show how Salesforce can act as the intelligent core of a modern customer engagement ecosystem. AWS captures digital events, Snowflake harmonizes enterprise data, Data Cloud creates unified profiles, SFMC activates journeys, and Agentforce drives intelligent recommendations.
