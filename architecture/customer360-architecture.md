# Customer 360 Architecture

This architecture connects AWS, Snowflake, Salesforce Data Cloud, SFMC, and Agentforce to support AI-powered customer engagement.

## Main Components

- AWS captures digital events.
- Snowflake stores and transforms customer data.
- Data Cloud unifies profiles and segments audiences.
- SFMC activates journeys and personalized campaigns.
- Agentforce recommends intelligent next actions.
